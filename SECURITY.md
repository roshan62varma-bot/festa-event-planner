# Security

## Reporting a vulnerability

Please open a private security advisory on GitHub (**Security → Report a vulnerability**) instead of a public issue. Include steps to reproduce. You can expect a reply within a few days.

## How Festa protects users

| Threat                            | Mitigation                                                                                                                                                                                                                                                                                             | Where                                                                 |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------- |
| API key exposure                  | Gemini is called only from the server; the key is read from the environment and never sent to the browser. `.env` is git-ignored.                                                                                                                                                                      | `server/ai/gemini.js`, `server/config.js`                             |
| Cross-site scripting              | Strict CSP (`script-src 'self'`, `object-src 'none'`, `frame-ancestors 'none'`). React escapes all text. No `dangerouslySetInnerHTML` (lint-enforced). AI colours reach CSS only if they match `#rrggbb`.                                                                                              | `server/http/security.js`, `src/lib/format.js`                        |
| Prompt injection                  | User text is sent only as an escaped JSON data block (every `<` is escaped as a Unicode sequence, so the block cannot be closed early), and the system prompt tells the model to treat it as data. AI output is re-validated: lengths clamped, lists bounded, enums enforced, budget maths recomputed. | `server/ai/prompts.js`, `server/services/sanitize.js`                 |
| Abuse and cost                    | Per-client rate limits: 120 requests a minute on the API, 15 a minute on generation. 16 KB body limit. JSON-only bodies (415 otherwise, which also blocks cross-site form posts). Request and header timeouts.                                                                                         | `server/http/routes.js`, `server/http/security.js`, `server/index.js` |
| Invalid input                     | One validator shared by client and server. Unknown fields are dropped; control characters are stripped.                                                                                                                                                                                                | `shared/validation.js`                                                |
| Information leaks                 | Errors return fixed messages. Stack traces and internal details are only logged on the server. `x-powered-by` is disabled.                                                                                                                                                                             | `server/http/errors.js`                                               |
| Guest privacy                     | Guest names never leave the browser. Only aggregate counts (attending, dietary totals) are sent to the AI. The plan is stored in the visitor's own browser storage, which is validated on load.                                                                                                        | `shared/guests.js`, `src/state/plannerReducer.js`                     |
| Clickjacking and browser features | `frame-ancestors 'none'`, `X-Frame-Options`, and a Permissions-Policy that disables camera, microphone, geolocation, payment and more.                                                                                                                                                                 | `server/http/security.js`                                             |
| Vulnerable dependencies           | `npm audit` of production dependencies runs in CI.                                                                                                                                                                                                                                                     | `.github/workflows/ci.yml`                                            |

These protections are covered by the tests in `tests/server/` and `tests/shared/`.
